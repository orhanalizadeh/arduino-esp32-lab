## 📚 Learning Goals

This repository is built around practical learning.

The main goals are:

* Understand microcontrollers
* Improve embedded C/C++ skills
* Learn how hardware and software interact
* Work with sensors and actuators
* Understand communication protocols
* Build Arduino and ESP32 projects
* Explore IoT concepts
* Practice writing clean and maintainable code
* Document projects professionally

---

## 🚀 Project Progression

Projects will gradually become more complex.

### 🟢 Fundamentals

GPIO, LEDs, buttons, buzzers, PWM and ADC.

### 🔵 Sensors & Modules

Temperature, humidity, light, distance, motion and other sensors.

### 🟣 Communication

UART, I²C, SPI, Bluetooth and Wi-Fi.

### 🟠 IoT

MQTT, HTTP, web servers, dashboards and connected devices.

### 🔴 Advanced Projects

Combining multiple sensors, communication protocols and embedded systems into complete applications.
